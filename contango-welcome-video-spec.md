# Contango — приветственный ролик для X

Спека на сборку 12-секундного видео к первому посту аккаунта.
Ролик рендерится кодом внутри существующего Next.js-приложения и снимается
покадрово — не генеративной моделью.

---

## 1. Почему кодом

Три вещи, которые генеративное видео не удерживает, а здесь нужны обязательно:

1. **Точный счёт.** Колец должно быть ровно двенадцать — по числу роллов в году.
   Модель даёт то одиннадцать, то тринадцать; на этом ломается утверждение поста.
2. **Чистые зоны под текст.** Типографика — половина кадра. Ей нужен предсказуемый
   фон, а не то, что домыслила модель.
3. **Повторяемость.** Правка одного такта не должна ронять остальные одиннадцать
   секунд.

Плюс сфера, палитра и гарнитуры уже существуют в проекте. Переиспользуем их,
а не подражаем им.

---

## 2. Параметры вывода

| | |
| --- | --- |
| Разрешение | 1920 × 1080 |
| Соотношение | 16:9 |
| Частота | 30 fps |
| Длительность | 12.0 с — ровно 360 кадров |
| Контейнер | MP4 |
| Видеокодек | H.264, profile High, `yuv420p` |
| Звук | нет |
| Размер файла | обязан быть < 512 МБ |

X принимает только H.264 — H.265, VP9 и AV1 отклоняются молча.

**Важно для дизайна:** ролики короче 60 секунд в ленте зацикливаются. Значит
последний кадр стыкуется с первым. Гасим финальную карточку в чёрный за
последние 6 кадров и выводим первый такт из чёрного за первые 6 — тогда петля
не дёргается.

## 3. Архитектура

Отдельный маршрут в приложении, например `/render`. Не часть публичного сайта —
страница нужна только для съёмки.

```
app/render/page.tsx     — канвас 1920×1080 + DOM-слой типографики
lib/welcome/scene.ts    — сцена three.js: сферы, кольца, фон
lib/welcome/timeline.ts — чистая функция кадра: frame -> состояние сцены
scripts/capture.mjs     — puppeteer, покадровая съёмка
```

Ключевое требование: **время берётся из номера кадра, не из часов.**

```ts
export function stateAt(frame: number) {
  const t = frame / 30;
  // всё положение, поворот, прозрачность выводится отсюда
}
```

В режиме съёмки цикл `requestAnimationFrame` выключен. Страница выставляет
наружу:

```ts
window.__renderFrame = async (i: number) => {
  applyState(stateAt(i));
  renderer.render(scene, camera);
  await document.fonts.ready;
};
window.__totalFrames = 360;
```

`renderer.setPixelRatio(1)` — иначе кадры поедут между машинами.

## 4. Сцена

**Камера.** `PerspectiveCamera`, fov 35, смотрит в начало координат.
Позиции по тактам — в разделе 5.

**Сфера.** Тот же объект, что в hero: `IcosahedronGeometry(1, 3)`,
рёбра через `WireframeGeometry` + `LineSegments`, материал
`LineBasicMaterial` без глубины свечения.

**Кольца.** Поверх правой сферы — двенадцать широтных `LineLoop`,
на широтах от −70° до +70° равномерно. Это те самые двенадцать роллов,
и число задаётся константой:

```ts
export const ROLLS = 12; // не менять — число роллов в году
```

**Левая сфера ничего не теряет и не меняется.** Не добавлять ей свечения,
роста или уплотнения: любой намёк на прирост читается как обещание доходности,
а это прямой запрет брифа. Всю мысль несёт асимметрия — одна теряет кольца,
вторая цела.

**Фон.** Вертикальный градиент `#040407 → #0C0C0F → #242866`, как на сайте.
Рисуется полноэкранным шейдером или CSS-подложкой под канвасом.

**Пыль.** Розовые точки `#AE749F`, очень редко — на сайте это 0.03% кадра.
Держать в тех же пределах, это акцент, а не звёздное небо.

## 5. Таймлайн

360 кадров. Границы тактов — жёсткие склейки без кроссфейдов.

| Такт | Кадры | Камера и сцена | Текст |
| --- | --- | --- | --- |
| 1 | 0–59 | Одна сфера крупно, `z = 2.6`, вращение 0.15 рад/с. Выход из чёрного за 6 кадров | нет |
| 2 | 60–125 | Отъезд до `z = 4.6`, сфера расходится надвое по X до ±1.6 | Сериф слева: `Two ways to hold oil.` |
| 3 | 126–185 | Держим. У правой сферы кольца отделяются по одному | Сериф слева: `Only one pays you for the wait.` |
| 4 | 186–227 | Наезд на правую сферу, `z = 1.9`, смещение камеры по X | Моно снизу слева, см. ниже |
| 5 | 228–251 | 3D скрыт, чистый фон | Цифра во весь кадр |
| 6 | 252–275 | 3D скрыт | Сериф по центру, две строки |
| 7 | 276–359 | 3D скрыт. Знак и вордмарк. Уход в чёрный за последние 6 кадров | Карточка, см. ниже |

**Отделение колец (такт 3).** Первое кольцо стартует на кадре 128, дальше
каждые 3 кадра. Полёт одного кольца — 22 кадра: радиус растёт с 1.0 до 1.9,
смещение по X до +0.8, прозрачность с 1 до 0. Последнее стартует на 161-м,
догорает к 183-му. Допустимо, чтобы хвост залезал в такт 4 — там тот же объект.

Движение ступенчатое, а не гладкое: пересчитывать положение колец не каждый
кадр, а каждый третий. На сайте в футере уже принят такой шаг, и он читается
как обновление данных, а не как дым.

## 6. Текстовые слои

Типографика — DOM поверх канваса, не внутри три. Шрифты брать из существующих
токенов проекта: сериф — тот же, что в hero, моно — тот же, что в фоновых
строках. Не подставлять свои.

Появление внутри такта: 8 кадров, `opacity 0→1` плюс сдвиг вверх на 12px.
Исчезновение — мгновенно на склейке.

**Такт 2 и 3.** Блок слева, отступ 120px, по вертикали по центру.
Сериф 64px, интерлиньяж 1.15, `#FFFFFF`, максимальная ширина 720px.

**Такт 4.** Снизу слева, отступ 120px.

```
1 / 1.005^12 = 0.9419
illustrative · one roll a month · constant premium · fees ignored
```

Первая строка — моно 24px `#757794`. Вторая — моно 15px `#43444D`.
Вторая строка **обязательна**: бриф требует помечать арифметику ролла
иллюстративной везде, где она показана.

**Такт 5.** По центру. Сериф, кегль ~340px, `#FFFFFF`:

```
2
```

Под цифрой линейка 4px цветом `#666CFF`, шириной по цифре. Ниже моно 20px
`#757794`:

```
oil-linked instruments on Robinhood Chain
```

Это единственное появление акцентного синего за весь ролик. Второй раз его
не использовать — иначе он перестаёт что-либо значить.

Почему двойка, а не процент: у референса на этом месте стоял параметр продукта.
Нам процент во весь экран запрещён — он прочтётся как наша доходность. Двойка
проверяема, лежит в брифе и формулирует саму предпосылку продукта.

**Такт 6.** По центру, сериф 72px, максимальная ширина 1200px, две строки:

```
Nothing was lost to a bad trade.
The shape of the curve took it.
```

Фраза взята из списка разрешённых к дословному переиспользованию.

**Такт 7.** По центру:

- знак-астериск, тот же что в шапке сайта, 64px
- `CONTANGO` — моно 40px, капслок, трекинг 0.18em, `#EFEFEF`
- отступ 28px, сериф 26px `#757794`:
  `A terminal for the two oil instruments on Robinhood Chain.`
- отступ 20px, моно 15px `#43444D`:
  `Not a broker. Not affiliated with Robinhood Markets. Not available in the US.`

Последняя строка закрывает пятый и шестой пункты хард-рулов прямо в кадре —
дисклеймер перестаёт быть припиской и становится частью карточки.

## 8. Фоновые моно-строки

На сайте в фоне лежит вывод valgrind: `Memcheck, a memory error detector`,
`Invalid read of size 1`, `parse_header (frame.c:214)`. Фактура рабочая,
но содержание чужое — детектор утечек памяти не имеет отношения ни к нефти,
ни к фьючерсам, и технический читатель это заметит.

В ролике набрать теми же кеглем и цветом, но своим:

```
chainId 4663
XOM  0xf9B46d3D1B22199D4D1025a9cEDB540A33F1a2d5
USO  0xa30FA36Db767ad9eD3f7a60fC79526fB4d56D344
settlement USDG
uiMultiplier() -> 4.0
permit(owner, spender, value, deadline, v, r, s)
front-month roll: sell expiring, buy next
```

Всё проверяемо, всё наше. Заодно стоит перенести это и на сайт.

## 9. Съёмка

```js
// scripts/capture.mjs
import puppeteer from 'puppeteer';
import fs from 'node:fs/promises';

const browser = await puppeteer.launch({
  args: ['--force-device-scale-factor=1', '--hide-scrollbars'],
});
const page = await browser.newPage();
await page.setViewport({ width: 1920, height: 1080, deviceScaleFactor: 1 });
await page.goto('http://localhost:3000/render?capture=1', {
  waitUntil: 'networkidle0',
});
await page.evaluate(() => document.fonts.ready);

await fs.mkdir('frames', { recursive: true });
const total = await page.evaluate(() => window.__totalFrames);

for (let i = 0; i < total; i++) {
  await page.evaluate((n) => window.__renderFrame(n), i);
  await page.screenshot({
    path: `frames/${String(i).padStart(4, '0')}.png`,
    omitBackground: false,
  });
}
await browser.close();
```

Съёмка идёт по шагам, а не в реальном времени — кадры не теряются, и результат
не зависит от нагрузки на машине.

## 10. Кодирование

```bash
ffmpeg -framerate 30 -i frames/%04d.png \
  -c:v libx264 -profile:v high -pix_fmt yuv420p \
  -crf 16 -movflags +faststart -an \
  contango-welcome.mp4
```

`-an` убирает дорожку. Если звук понадобится, добавлять его отдельным решением,
а не побочным эффектом генерации.

Проверить после сборки:

```bash
ffprobe -v error -show_entries \
  stream=codec_name,profile,pix_fmt,width,height,r_frame_rate \
  -show_entries format=duration,size contango-welcome.mp4
```

## 12. Текст поста

Ролик идёт с этим текстом. Кадр и текст должны говорить одно и то же.

```
There are exactly two oil-linked instruments on Robinhood Chain.

XOM sells the barrel and pays a dividend.
USO holds front-month futures and pays to roll them.

Both track the same commodity. While the curve is in contango,
only one of them leaks on a schedule.

Contango tracks the gap. Not available in the US.
```

Оговорка «while the curve is in contango» обязательна. Ролик показывает потерю
как постоянный процесс, а бриф запрещает подавать контанго постоянным
состоянием — условие несёт текст.
